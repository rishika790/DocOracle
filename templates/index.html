Architecture

How DocMind Works

A transparent, enterprise-grade RAG pipeline — every step designed for accuracy and speed.

01

Upload & Parse

Drop any PDF up to 16 MB. The engine uses PyMuPDF for high-fidelity text extraction preserving document structure.

PyMuPDF · Flask
02

Semantic Chunking

Text is split into overlapping chunks with intelligent boundary detection to preserve context across passages.

LangChain · RecursiveTextSplitter
03

Dense Embeddings

Each chunk is encoded into a 384-dimensional dense vector using the all-MiniLM-L6-v2 sentence transformer.

SentenceTransformers · MiniLM-L6
04

FAISS Retrieval

Your query is embedded and matched against stored vectors using cosine similarity search, returning top-K most relevant passages.

FAISS · Inner Product Search
05

Grounded Generation

Retrieved passages are injected as context into a structured prompt. LLaMA 3.3 70B generates factual, cited answers strictly from document content.

Groq API · LLaMA 3.3 70B
